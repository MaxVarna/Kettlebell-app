# Анимации упражнений

Эта папка зарезервирована для исходников, экспортов и метаданных instructional-анимаций упражнений. Предпочтительный кандидат — Rive, но формат будет подтверждён только после prototype на реальных устройствах.

Граница папки: анимация помогает понять движение и остаётся видимой в рабочем интервале. Она не распознаёт технику, не считает повторения и не делает медицинских выводов. Для Reduce Motion должны существовать статичные ключевые кадры.

Файлы анимаций можно добавлять после утверждения контентного pipeline, лицензионных прав, требований к размеру ассетов и accessibility fallback. До этого здесь нет бинарных ассетов или runtime-конфигурации.
