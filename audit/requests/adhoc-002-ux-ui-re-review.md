# Audit Request adhoc-002 — UX/UI re-review after remediation (off-cycle)

**Версия запроса:** 1  
**Ожидаемый отчёт:** `audit/reports/adhoc-002-ux-ui-re-review-report.md`

> Внеплановый повторный UX/UI-аудит по прямому запросу владельца. Проверка
> исправлений после `003-ux-ui-runner-review`. Вне стандартных gate 001–004.

## Цель аудита

Проверить регрессии основного сценария и закрытие замечаний из Audit 003 на
обновлённой сборке; отдельно оценить считываемость трёх фаз с мобильного экрана.

## Scope

### In scope

- Мобильный viewport (390×844) веб-предпросмотра.
- Основной сценарий: главная → конструктор → карточка движения → runner
  (подготовка/работа/отдых) → пропуск → завершение → итог.
- Заявленные изменения после Audit 003 (список ниже).
- Считываемость трёх фаз.

### Out of scope (по прямому указанию владельца — НЕ считать замечаниями)

- Web-растягивание вёрстки и крупная CTA пустого состояния на десктопе:
  web — только среда предпросмотра, не целевой продукт.
- Горизонтальные степперы: утверждён паттерн «плюс сверху, значение, минус снизу».
- Кнопка возврата к предыдущему интервалу: не добавляется (есть только «Пропустить»).
- Drag-and-drop перестановки: не на этом этапе; увеличены тап-зоны стрелок.
- Яркие коралловые/зелёные заливки всего экрана: намеренно не используются —
  визуальный характер спокойный, собранный, инструментальный.
- Анимация упражнений: отдельный будущий этап, сейчас утверждённые статичные иллюстрации.
- Вес, повторения, подходы, калории, силовая аналитика: вне концепции.

## Заявленные изменения после Audit 003

1. Runner: разные спокойные цвета фаз; цвет применён к слову фазы, линии прогресса
   и полупрозрачному кругу за фигурой; фигура выходит за верх круга; круг увеличен.
2. Подтверждение «Завершить» ставит таймер на паузу.
3. Увеличены тап-зоны степперов и стрелок перестановки.
4. Тумблер звука + локальные офлайн-сигналы (3-2-1, старт работы/отдыха); haptic и
   Wake Lock реализованы.
5. «Пропустить» с подтверждением вторым касанием.
6. Естественное завершение последнего цикла → экран итога; ручное «Завершить» —
   прерывание → главная.
7. Убрана подпись «Ключевая позиция».

## Что проверить в первую очередь

1. Регрессии основного сценария на мобильном viewport.
2. Считываемость подготовки/работы/отдыха.
3. Фактическое закрытие пунктов 1–7.

## Критерии оценки

- Разделить наблюдаемое / предположение / непроверяемое в web.
- Звук по статичному браузерному просмотру не считать отсутствующим.
- Результат по P0–P3, с вердиктом.
