# Запросы аудита

Маска фактического запроса: `[0-9][0-9][0-9]-<topic>.md`, например `001-mvp-architecture.md`.

Каждый запрос создаётся по [TEMPLATE.md](TEMPLATE.md), получает уникальный номер и явно перечисляет файлы, которые auditor может читать. Не помещайте сюда рабочие заметки, секреты или файлы реализации.
