Повторный аудит на мобильном viewport 390px. Пройден полный путь: главная →
конструктор → карточка движения → последовательность → runner

Блокеров нет. Остаток — уровня P3 и проверки, возможные только на реальном
устройстве (звук/haptic/Wake Lock и дистанционная читаемость цвета).

## Проверка заявленных изменений (Audit 003 → текущая сборка)

1. 🟢 **Цвета фаз.** Подготовка — прохладный сине-серый, Работа — тёплый янтарь,
   Отдых — зелёный. Цвет применён к слову фазы, линии прогресса и кругу за фигурой.
   Фигура выходит за верх круга, круг увеличен. Заливки спокойные (не яркие) — по замыслу.
2. 🟢 **Пауза при «Завершить».** Замерено: таймер замер на 00:11 и не изменился за
   2.2 с; при подтверждении подпись меняется на «ПАУЗА», кнопки «Подтвердить
   завершение / Продолжить».
3. 🟢 **Тап-зоны.** Замерено из DOM: степперы «+/−» = 44×44px, back-шеврон = 48×48px
   (iOS HIG 44pt соблюдён).
4. 🟢 **Тумблер звука** присутствует в шапке runner. ⚪ Сами сигналы (3-2-1,
   старт работы/отдыха), haptic и Wake Lock в браузере не проверяются; по статике
   их отсутствие не констатируется — приняты как реализованные, проверка на устройстве.
5. 🟢 **«Пропустить» с подтверждением.** Первое касание → кнопка «Точно?», второе → пропуск.
6. 🟢 **Экран итога.** Естественное завершение последнего цикла → «Тренировка
   завершена · 3 мин · 3 цикл.» со списком последовательности и «На главную / Повторить».
   Ручное «Завершить» — прерывание.
7. 🟢 **«Ключевая позиция» убрана** — подписи под названием движения на runner нет.

Дополнительно: 🟢 муляж «Задействованные зоны» на карточке движения содержит две
иллюстрации (упражнение + карта мышц), обе присутствуют в DOM (регрессии из
прошлого визуального наблюдения нет).

## Считываемость трёх фаз (отдельная оценка)

🟢 Три фазы различимы: сигнал несут одновременно цвет слова фазы, линия прогресса
и тонированный круг; тона (прохладный/янтарный/зелёный) явно разные. Относительно
v1 (только мелкая подпись + линия) — существенное улучшение; основная претензия
Audit 003 (P1-1) закрыта.

🟡 В рамках осознанного «спокойного, не яркого» характера: крупнейший элемент —
таймер — во всех фазах чёрный, а цветовой сигнал несут слово фазы (капс ~14px) и
мягкий тон круга. Тон круга при беглом взгляде деликатный. Внутри выбранной
эстетики приемлемо; ярких заливок не предлагается (исключены владельцем).

⚪ Реальная читаемость «с пола, боковым зрением, в ярком зале» браузером не
воспроизводится — проверяется только на устройстве с реальной дистанции.

## P3 — улучшения (не блокируют)

**P3-1.** 🟡 Экран итога визуально пустоват: контент прижат вверх, большая пустая
зона до кнопок. В рамках минимализма приемлемо; при желании — лёгкая сводка
(суммарное рабочее время / число интервалов), без веса/повторов/калорий.

**P3-2.** 🟡 (Опционально, в рамках «спокойного» характера.) Для дистанционной
читаемости — чуть крупнее слово фазы либо чуть насыщеннее тон круга, без ярких
заливок. Только если тесты на устройстве покажут нехватку сигнала.

**P3-3.** ⚪ (Перенос из Audit 003.) Контраст светло-серых подписей к WCAG AA
точно не измерялся — прогнать инструментом.
