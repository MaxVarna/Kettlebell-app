# Заключения аудита

Маска отчёта: `[0-9][0-9][0-9]-<topic>-report.md`, где `<topic>` совпадает с запросом из `audit/requests/`.

Например, результат для `001-mvp-architecture.md` хранится как `001-mvp-architecture-report.md`. Отчёт должен сохранять исходные findings и не заменять решение владельца проекта.
