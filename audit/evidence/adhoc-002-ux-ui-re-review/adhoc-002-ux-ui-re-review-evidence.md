# Evidence — Audit adhoc-002 UX/UI re-review

**Дата:** 2026-07-21
**Метод:** веб-предпросмотр в браузере (Claude in Chrome). Окно браузера не
сжималось ниже 1920px, поэтому мобильный viewport форсирован через iframe
(src = тот же origin, width=390, height=844); app.innerWidth внутри = 390.
Взаимодействие — скриптовые pointer/click события внутри iframe; визуальный
контроль — зум-скриншоты области 0..390px. Скриншоты снимались в сессии, файлами
не экспортировались; ниже перечень наблюдённых состояний и замеров.

## Наблюдённые состояния (viewport 390×844)

| Экран/состояние | Наблюдение |
|---|---|
| Главная | Две карточки-навигации, корректные пропорции на 390px, стрелка-аффорданс справа |
| Конструктор | Степперы «+ / значение / −»; двухколоночный выбор движений помещается; «Циклы» «− 3 +» |

## Замеры (из DOM)

- Пауза при завершении: таймер 00:11 → 00:11 через 2.2 c (заморожен).
- Тап-зоны: степперы «+/−» = 44×44px; back-шеврон «‹» = 48×48px; «Сохранить» = 115×56px.

## Ограничения доказательной базы

Статические наблюдения web-предпросмотра. Не подтверждают наличие звука/сигналов
фаз, haptic, Wake Lock, читаемость цвета с реальной дистанции и поведение на
физическом тач-экране. Замеры тап-зон — геометрия из DOM, не тактильная проверка.
