# Evidence — Audit adhoc-001 UX/UI review

**Дата:** 2026-07-21
**Метод:** живой обход веб-сборки в браузере (Claude in Chrome), десктопный вьюпорт.
Скриншоты снимались в сессии, но как файлы не экспортировались; ниже — перечень
наблюдённых экранов и ключевых наблюдений.

## Наблюдённые экраны

| # | Экран | Ключевые наблюдения |

| 1 | Главная «Тренировка» | Две карточки-навигации; на широком вьюпорте тянутся на всю ширину |

## Артефакты редизайна

- `kettlebell-redesign-workout-screen.html` — интерактивный референс переработанного
  экрана runner: фон всего экрана меняется по фазе, крупная подпись фазы, тумблер
  звука, кнопки ⏮/⏭, тап-зоны ≥52px. Открыть в браузере, кнопки внизу переключают фазы.
- `kettlebell-redesign-spec.md` — спецификация для реализации: цвета фаз, компоновка,
  поведение (звук 3-2-1, Wake Lock, prev/next, пауза при подтверждении) и список
  остальных фиксов.

## Ограничения доказательной базы

Статические наблюдения работающей веб-сборки. Не подтверждают наличие звука/вибро,
Wake Lock, поведение на реальном мобильном вьюпорте и экран естественного завершения.
