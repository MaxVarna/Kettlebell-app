# Kettlebell Interval — спецификация редизайна экрана тренировки

Референс-рендер: `kettlebell-redesign-workout-screen.html` (открыть в браузере, кнопки внизу переключают фазы).
Это концепт-направление для реализации, не финальные пиксели. Цвета/иконки подогнать под бренд.

## Что решаем (из UX-аудита)
1. **Glanceability фазы** — сейчас фаза различается только мелкой подписью и цветом полоски. Фон всего экрана должен меняться по фазе.
2. **Тап-зоны < 44px** — все контролы довести до ≥52px.
3. **Нет звука/вибро/пропуска интервала** — добавить видимый тумблер звука и кнопки prev/next.

## Фазы и цвета фона (весь экран)
| Фаза | Ключ | Фон | Цвет подписи фазы |
|------|------|-----|-------------------|
| Подготовка | `prep` | `#D3D1C7` (нейтральный серый) | `#2C2C2A` |
| Работа | `work` | `#F0997B` (тёплый коралл) | `#4A1B0C` |
| Отдых | `rest` | `#5DCAA5` (спокойный зелёный) | `#04342C` |

Переход фона: `transition: background .35s ease`. Цифры таймера и иконки — тёмные (`#1f1f1f`) на всех фонах (контраст проверить под AA).

## Компоновка (сверху вниз)
- **Топбар:** слева счётчик `Цикл N / M`; справа тумблер «Звук» (иконка `ti-volume`), пилюля, тап-зона ≥44px.
- **Центр:** круглая иллюстрация движения (116px) → крупная подпись фазы (28px/600) → название движения (14px, приглушённое) → таймер (78px/600, `tabular-nums`) → полоса прогресса (высота 6px, заполнение = прошедшая доля интервала).
- **Контролы:** ⏮ (56px круг) · «Пауза» full-width (высота 56px, тёмная) · ⏭ (56px круг).
- **Подпись «Дальше»:** что за интервал следующий (`Дальше · Отдых 20с`).

## Поведение
- **Звук:** сигнал за 3-2-1 секунды до смены фазы + сигнал в момент смены. Тумблер сохраняет состояние.
- **Wake Lock:** удерживать экран включённым во время активной тренировки (Screen Wake Lock API).
- **Пауза:** останавливает отсчёт; на паузе подпись «Пауза» → «Продолжить».
- **Prev/Next (⏮/⏭):** переход к предыдущему/следующему интервалу без выхода из тренировки.
- **Завершить:** отдельная маленькая кнопка (не на этом слое — в углу/меню), с подтверждением; **на время подтверждения таймер ставить на паузу** (сейчас он продолжает тикать — баг).

## Прочие фиксы приложения (вне этого экрана)
- Обернуть всё приложение в контейнер `max-width: 480px; margin: 0 auto` — чинит растягивание на десктопе/планшете.
- Кнопку пустого состояния «Создать первую» ограничить (`max-width: 320px`, высота ~52px), отцентрировать.
- Степперы «Ритм цикла» унифицировать с блоком «Циклы» — горизонтальный `− значение +`, тап-зоны ≥44px.
- Добавить экран итога после завершения тренировки (время, циклы, движения, «Повторить»/«Сохранить»).
