# UI и дизайн-система

Эта папка зарезервирована для будущей общей дизайн-системы: цветовых токенов, типографики, компонентов, правил доступности, звука, haptic-отклика и согласованного движения интерфейса.

Граница модуля: UI задаёт представление и доступное взаимодействие, но не принимает решения о сохранении результатов тренировки. Все сценарии должны поддерживать крупный текст, экранные дикторы, высокую контрастность и Reduce Motion.

Код и дизайн-токены могут быть добавлены после утверждения визуального направления и prototype ключевого полноэкранного сценария. Никаких библиотек, package manifests или готовой реализации до этого этапа здесь не создаётся.
