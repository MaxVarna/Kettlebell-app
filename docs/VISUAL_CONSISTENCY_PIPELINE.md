# Контроль однородности фигур между фазами

## Проблема

Одинаковый холст, линия стоп и общий масштаб не гарантируют, что в соседних кадрах изображён один и тот же человек. Генератор может изменить размер головы, ширину плеч, толщину рук, бёдер или икр. Равномерное уменьшение всего кадра такую ошибку не исправляет.

## Принцип

Фигура проверяется в два независимых прохода:

1. **Геометрия позы** — положение суставов, порядок фаз, рабочая сторона и линия стоп.
2. **Идентичность телосложения** — длины костных сегментов и толщина частей тела.

Масштаб и положение можно исправлять автоматически только равномерным преобразованием всего кадра. Различия пропорций нельзя исправлять растяжением отдельных частей: такой кадр бракуется и перерисовывается.

## Канонический паспорт фигуры

Для каждого сочетания `styleId + figureVariant` хранится один утверждённый паспорт в нейтральной стойке:

- контрольные точки: макушка, подбородок, плечи, локти, запястья, таз, колени, щиколотки и стопы;
- длины сегментов: плечо, предплечье, бедро и голень;
- ширина головы, плеч, грудной клетки, таза;
- толщина бицепса, предплечья, бедра и икры;
- высота фигуры и уровень стоп;
- эталонные изображения спереди, сбоку и в три четверти.

Мужская и женская фигуры имеют разные паспорта и никогда не сравниваются друг с другом.

## Автоматическая проверка кадра

### 1. Входной контроль

- холст и альфа-канал соответствуют контракту;
- фигура полностью помещается в кадр;
- фон прозрачен;
- гиря присутствует;
- ракурс совпадает с `poseBrief`.

### 2. Скелет

Из кадра извлекаются суставные точки. Для согнутой позы нельзя использовать высоту bounding box: она меняется из-за движения. Масштаб оценивается по медиане отношений устойчивых сегментов:

`плечо + предплечье + бедро + голень`.

Сегменты с сильным перспективным сокращением исключаются. После этого ко всему кадру применяется только единый коэффициент масштаба.

### 3. Толщина частей тела

По альфа-маске измеряются поперечные сечения перпендикулярно оси соответствующего сегмента:

- бицепс — середина плеча;
- предплечье — середина предплечья;
- бедро — середина бедра;
- икра — наиболее широкая треть голени;
- голова, плечи, грудная клетка и таз — по отдельным контрольным сечениям.

Для каждого показателя берётся медиана нескольких соседних сечений, чтобы линия одежды или мелкая деталь не искажала результат.

### 4. Порог допуска

После нормализации относительно канонического паспорта:

| Показатель | Допустимое отклонение |
|---|---:|
| длина сегмента | до 4% |
| голова и ширина плеч | до 5% |
| грудная клетка и таз | до 6% |
| бицепс, предплечье, бедро и икра | до 7% |
| линия стоп между фазами | до 1% высоты холста |

Выход за порог хотя бы по двум параметрам или более чем в 1,5 раза по одному параметру означает `rejected`. Кадр нельзя переводить в `reviewed` ручной подгонкой масштаба.

## Генерация без накопления ошибок

1. Сначала создаётся единый storyboard всех двух или трёх фаз с канонической фигурой в одном масштабе.
2. Каждая фаза получает тот же паспорт фигуры, соседние фазы и скелет целевой позы как обязательные референсы.
3. Фазы вырезаются из storyboard без независимого масштабирования.
4. Валидатор рассчитывает паспорт каждого кадра и формирует отчёт.
5. При несовпадении пропорций перерисовывается только проблемный кадр, но с канонической фигурой и ближайшим прошедшим проверку кадром в качестве референсов.

## Отчёт валидатора

Для каждого набора фаз сохраняются:

- JSON с измерениями и отклонениями;
- наложение полупрозрачных скелетов;
- контактный лист всех фаз с общей линией стоп;
- список `pass/warn/reject` по каждому параметру.

Статус визуалов может стать `reviewed` только после автоматического `pass`. Финальный `approved` остаётся ручным решением после просмотра анимации на телефоне.

## Решение для текущей становой тяги

Текущая пара не проходит проверку идентичности телосложения: равномерная коррекция масштаба не устраняет различия икр, рук и других частей тела. Оба мужских кадра нужно пересобрать из одного канонического storyboard, затем повторить автоматическую и ручную проверку.
