# Motion language: движения в runner-е

Статус: рабочая спецификация. Эта система описывает визуальное сопровождение движения; она не обучает технике и не заменяет проверку с сертифицированным тренером.

## Роль анимации

Анимация отвечает на один вопрос: **куда идёт движение сейчас**. Она не считает повторения, не задаёт темп пользователя и не соревнуется с таймером за внимание.

Во время фазы работы экран одновременно сообщает:

1. режим и оставшееся время — крупной типографикой;
2. название упражнения — словами;
3. направление движения — простой анимацией.

Если пользователь видит экран лишь мгновение, время и режим считываются первыми. Если смотрит дольше, движение становится понятнее без чтения инструкции.

## Состав одного motion-asset

Каждое поддержанное упражнение получает канонический набор из двух или трёх прозрачных ключевых кадров в утверждённом стиле. Количество кадров определяется числом действительно различимых фаз движения, а не единым шаблоном для каталога.

- **исходная поза** — первый полный кадр движения;
- **промежуточная поза** — добавляется только там, где две крайние точки недостаточны для понимания;
- **целевая поза** — последний полный кадр движения;
- **ключевой кадр для миниатюры** — наиболее узнаваемая поза без анимации;
- **минималистичный режим** — изображения упражнения полностью скрыты; остаются только название движения, текущая фаза и таймер.

Минималистичный режим не пытается уместить фазы движения на малом экране. Название, фаза и таймер выровнены по центру и получают увеличенную типографику; во время подготовки и отдыха название упражнения скрыто.

Все кадры одного упражнения помещаются на одинаковый прозрачный холст. Масштаб тела сохраняется, а стопы совмещаются с общей нижней базовой линией. Поэтому при crossfade фигура меняет позу, но не подпрыгивает целиком.

## Поведение в runner-е

### Работа

Это единственная фаза, где визуализация движется.

Один тихий цикл длится примерно 2–3 секунды:

1. исходная поза удерживается достаточно долго для считывания;
2. текущий кадр гаснет, затем следующий проявляется через короткий fade-through без одновременного наложения двух фигур;
3. при наличии третьей фазы она проявляется тем же способом;
4. короткая пауза удерживает целевую позу;
5. следующий цикл проходит по обратной последовательности через промежуточные позы, без скачка из последнего кадра в первый.

Для первого релиза используется только opacity в неподвижном слое иллюстрации. Нет видео, 3D, пульсаций, прыжков, частиц и декоративного движения фона.

### Подготовка, отдых и переход

Активная анимация не работает. Предстартовый экран и подготовка используют одну энергичную стойку готовности без гири. По умолчанию подготовка показывается только один раз в начале всей тренировки. В настройках конкретной тренировки это можно отключить, чтобы подготовка повторялась в начале каждого полного цикла. Между упражнениями новой подготовки нет: после отдыха сразу начинается работа следующего упражнения. Отдых показывает отдельную расслабленную стоячую позу без гири. Эти состояния не используют кадры конкретного упражнения.

Последовательность кадров всегда замкнута обратным проходом: два кадра идут `1 → 2 → 1`, три кадра — `1 → 2 → 3 → 2 → 1`. Прямой скачок из последней позы в первую запрещён. Порядок строится общей функцией и покрывается тестами, а не задаётся отдельно внутри каждого упражнения.

### Пауза, фон и возврат

- при паузе цикл замораживается на текущем читаемом кадре;
- в фоне анимация останавливается полностью, а таймер продолжает рассчитываться по монотонному времени;
- после возврата приложение сначала восстанавливает фактическую фазу и время, затем запускает новый цикл анимации с начала. Оно никогда не пытается «догнать» пропущенный кадр;
- при смене упражнения старый силуэт исчезает, новый начинается с его исходной позы. Переход занимает не более 250 мс и не задерживает таймер.

## Использование на других экранах

- **Сохранённые схемы:** только статичная миниатюра из того же asset; без ghost-позы, если она теряется на маленьком размере.
- **Сборка и каталог движений:** статичные ключевые кадры по умолчанию; короткий preview-loop запускается только после явного выбора движения или на крупном экране детали.
- **Следующее движение в runner-е:** статичная миниатюра, чтобы активное движение оставалось единственным анимированным объектом.

## Доступность и производительность

- При отключённой анимации или системном Reduce Motion изображения упражнения не показываются. Во время работы остаются крупные название движения, режим и таймер; во время подготовки и отдыха — только режим и таймер. Цвет ничего не сообщает в одиночку.
- Пользователь может отключить анимацию отдельно от звука и haptic-сигналов.
- Цель — плавность на целевых устройствах; анимация не должна занимать основной поток и не должна менять layout экрана.
- Asset хранится локально, работает без сети и не блокирует старт сессии. Если asset не загрузился, runner показывает название упражнения, таймер и нейтральную статичную пиктограмму.

## Контроль качества перед выпуском упражнения

1. Тренер подтверждает, что исходная, целевая позы и траектория не противоречат базовой безопасной технике.
2. Пользователь узнаёт движение по миниатюре с подписью на маленьком размере.
3. Цикл остаётся вторичным по отношению к таймеру в светлой и тёмной теме.
4. Минималистичный Reduce Motion экран понятен без изображения и анимации.
5. Анимация плавна, не расходится с таймером и корректно возобновляется после фона.
