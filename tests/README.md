# Проверки

Эта папка зарезервирована для будущей стратегии, сценариев и результатов проверок. Пока она не содержит автоматических тестов или конфигурации тестового запуска.

Критические будущие сценарии: полный путь каталог → «Сегодня» → тренировка → история; некорректные данные конструктора; пауза, сворачивание, блокировка и принудительное закрытие в каждой фазе; отсутствие сети; отказ в уведомлениях; смена часового пояса и времени; accessibility; проверка на реальных Android- и iOS-устройствах.

После добавления синхронизации также проверяются повторы операций, дубликаты, конфликты устройств, перенос гостевых данных в аккаунт и удаление аккаунта.

Тестовый код, тестовые данные и инструменты могут быть добавлены после появления утверждённого приложения или доменных контрактов. Реальные пользовательские данные для тестирования не используются.
