# Мобильное приложение

Актуальный Expo/React Native-клиент интервальных тренировок с гирей для Android, iOS и web-предпросмотра.

## Продуктовая граница

Приложение является интервальным runner-ом, а не силовым дневником. Пользователь:

1. выбирает последовательность движений;
2. задаёт единые подготовку, работу и отдых для всей схемы;
3. сохраняет или сразу запускает схему;
4. проходит цикл по таймеру с визуальными, звуковыми и haptic-сигналами.

Вес, повторения, подходы, тоннаж и автоматическая оценка техники в текущую модель не входят.

## Режимы runner-а

- С анимацией: 2–3 ключевые фазы движения сменяются последовательным fade.
- Без анимации / Reduce Motion: изображения скрыты; остаются крупные название движения, фаза и таймер. На подготовке и отдыхе название упражнения не показывается.

Подготовка запускается один раз в начале каждого полного цикла. Между движениями используются отдых и непосредственный переход к работе следующего движения.

## Локальная разработка

Из корня `D:\Kettlebell app`:

```powershell
npm run mobile:start
npm run mobile:typecheck
npm run mobile:test
npm run mobile:export:android
```

Данные схем и настроек хранятся local-first. Сетевое подключение не требуется для прохождения тренировки.
