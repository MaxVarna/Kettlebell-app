# 2D rigs for motion assets

Риг — производственный источник, а не runtime-формат мобильного приложения. Из одного мастер-рисунка офлайн собираются обычные PNG-фазы, которые затем проходят `validate_figure_consistency.py` и попадают в каталог.

Правила:

1. Голова, корпус, свободная рука и ноги принадлежат одному мастер-слою и не перерисовываются между фазами.
2. Рабочая рука разделяется в точках `shoulder → elbow → wrist`; длины сегментов берутся только из master и не задаются в позах.
3. Поза хранит только углы. Кисть и гиря имеют отдельные pivot-точки; гиря сохраняет вертикаль под действием тяжести.
4. Master со статусом `draft` нельзя экспортировать в приложение. Сначала владелец утверждает стиль, затем создаются маски слоёв и ставится `approved`.
5. Любой экспортированный кадр всё равно обязан получить landmark-manifest и отчёт `pass`.
6. `visualReference` указывает на утверждённую фигуру. Черновой master можно менять, но нельзя считать готовым к нарезке, пока голова, корпус и пропорции визуально не сверены с этим эталоном.

Проверка:

```powershell
python services/content/scripts/validate_rig_manifest.py `
  --manifest services/content/rigs/clean-press-female/rig.v1.json `
  --report services/content/rigs/clean-press-female/rig-validation-v1.json
```
