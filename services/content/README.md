# Контент каталога и программ

Эта папка зарезервирована для будущих контрактов и материалов каталога упражнений, готовых программ, подсказок, предупреждений и манифестов анимаций.

Граница модуля: контент должен быть версионирован. Активная и завершённая тренировка использует снимок на момент старта, поэтому позднее обновление каталога не меняет прошлые результаты. Публикация контента в будущем допускается только доверенным серверным процессом; клиент читает опубликованный контент.

На текущем этапе сервер, API, база данных и автоматическая публикация не создаются. Контракты или контентные образцы можно добавлять только после решения о формате, версиях, валидации и правах редакторов.
