# Kettlebell App

Канонический рабочий каталог мобильного интервального runner-а для тренировок с гирей.

## Канонические контуры

- Локальный проект: `D:\Kettlebell app`
- Мобильное приложение: `D:\Kettlebell app\apps\mobile`
- GitHub: `https://github.com/MaxVarna/Kettlebell-app`
- Продуктовая и техническая документация: `docs/`
- Запросы, отчёты и evidence аудита: `audit/`

Каталог `C:\Users\Максим\Documents\Приложение для гиревых тренировок` сохранён только как временная страховочная копия после объединения 22.07.2026 и больше не должен использоваться для разработки.

## Текущий продукт

Приложение позволяет собрать последовательность гиревых движений, задать единый ритм подготовки, работы и отдыха, сохранить схему и пройти тренировку по точному таймеру. Повторы, подходы и вес не отслеживаются.

Runner поддерживает два режима:

- анимированный — ключевые фазы движения сменяются через fade;
- минималистичный — без изображений, с крупными названием движения, фазой и таймером.

Основные решения зафиксированы в [PRODUCT.md](docs/PRODUCT.md), [DESIGN.md](docs/DESIGN.md), [PROJECT_ACTION_PLAN.md](docs/PROJECT_ACTION_PLAN.md) и [MOTION_LANGUAGE.md](docs/MOTION_LANGUAGE.md).

## Структура

```text
.
├── apps/mobile/          актуальное Expo-приложение Android/iOS/web
├── packages/ui/          место для общей дизайн-системы
├── assets/               общие исходные материалы проекта
├── services/content/     будущий контур базы упражнений и контента
├── audit/                аудит, evidence и локальные инструменты аудита
├── docs/                 продуктовые, UX- и технические документы
├── skills/               проектные рабочие скиллы
└── tests/                общая стратегия и материалы проверки
```

## Команды

Из корня проекта:

```powershell
npm run mobile:start
npm run mobile:typecheck
npm run mobile:test
npm run typecheck
npm test
```

Проверочная Android-сборка:

```powershell
npm run mobile:export:android
```
