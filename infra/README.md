# Инфраструктура и среды

Эта папка зарезервирована для будущей документации инфраструктуры, окружений и безопасных процедур поставки.

Граница модуля: MVP не требует сервера. Позднее понадобятся полностью отдельные staging и production среды для аккаунтов, резервной копии, синхронизации и обновляемого контента. Предварительный вариант — отдельные проекты Supabase с Postgres, авторизацией и хранилищем файлов; это не утверждённая конфигурация.

Нельзя добавлять сюда секреты, `.env`-файлы, ключи, учётные данные, провайдерские конфигурации, Terraform, CI или серверные проекты до принятия архитектурного решения, модели доступа и процедуры управления секретами.
